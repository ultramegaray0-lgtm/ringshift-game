Privacy Policy

Last updated: November 6, 2026

This policy explains how the Ringshift game and the maintainer’s optional Ringshift Social API integration (together, the “Service”) handle information. If you are here to play the game, the first two sections are the ones that apply to you.

Playing the game

The Ringshift game runs entirely in your web browser. It saves your progress and settings in your browser’s local storage, on your own device. The game does not send that data to us, and it has no accounts, ads, analytics, trackers or cookies of its own, and it makes no network requests while you play. You can delete your save at any time with Options → Reset Save Data in the game, or by clearing the site’s data in your browser. Options → Back Up Progress lets you keep a copy of your save as a file or code; that copy stays wherever you put it.

Where the game is hosted

itch.io. When you play Ringshift on itch.io, the game runs inside itch.io’s page. itch.io may collect information about your visit (for example page views, downloads and, if you are signed in, your itch.io account) under the itch.io Privacy Policy. As the developer, we see only the aggregated statistics itch.io shows creators (such as views, plays, downloads and referring sites); we do not see your personal information. Your save is stored in your browser for itch.io’s game domain, separately from the save on the GitHub Pages version.

GitHub Pages. The Ringshift website at ultramegaray0-lgtm.github.io/ringshift-game is hosted by GitHub Pages. GitHub states that when a GitHub Pages site is visited, the visitor’s IP address is logged and stored for security purposes (see GitHub’s documentation and the GitHub General Privacy Statement).

If you play Ringshift on any other website that hosts it, that website’s own privacy policy applies to your visit there.

Optional TikTok integration

The maintainer uses an optional integration to send gameplay videos to the maintainer’s own TikTok inbox. Players never use it, and nothing in the game connects to TikTok. The rest of this section describes that integration.

Information handled

If you choose to use the optional TikTok integration, the workflow handles the TikTok authorization information needed to upload a video to your own TikTok inbox, along with the video file and the upload details needed to complete the request.

How information is used

Information is used only to authenticate the TikTok account you authorized, transfer the video you selected to TikTok as an inbox draft, maintain the authorization needed for later uploads, and diagnose or secure the workflow. The integration does not publish videos automatically.

Storage and service providers

The integration runs through GitHub Actions. TikTok credentials and refresh-token state are intended to be stored as GitHub Actions secrets and encrypted state, respectively. Video artifacts and workflow logs may be retained by GitHub according to the repository and GitHub Actions retention settings. TikTok receives the video and related upload data as part of the upload process and handles them under TikTok's own policies.

Retention and control

Workflow artifacts and logs are retained according to the configured GitHub settings. You can stop using the integration and revoke its authorization through your TikTok account's connected-app settings. You can also remove the related GitHub Actions secrets to prevent further uploads.

Sharing

We do not sell personal information. Information from the TikTok integration is shared with TikTok only as needed to perform the upload you request, and with GitHub as needed to run and store workflow data. We do not intentionally collect information for advertising.

Security

Reasonable safeguards are used, including encrypted storage for refresh-token state and GitHub's encrypted secrets. No internet service can guarantee absolute security.

Children

The Service is not designed to collect personal information from children, and the game itself collects none from anyone.

Changes and contact

This policy may be updated as the Service changes. For privacy questions, contact the project maintainer through the Ringshift GitHub repository or through Ringshift’s itch.io page.
