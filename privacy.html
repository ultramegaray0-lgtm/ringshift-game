Ringshift

Privacy Policy

Last updated: November 2, 2026

This policy explains how the Ringshift website and optional Ringshift Social API integration (the “Service”) handle information.

Information handled

The public Ringshift game website is a static website and does not ask visitors to create an account. If you choose to use the optional TikTok integration, the workflow handles the TikTok authorization information needed to upload a video to your own TikTok inbox, along with the video file and the upload details needed to complete the request.

How information is used

Information is used only to authenticate the TikTok account you authorized, transfer the video you selected to TikTok as an inbox draft, maintain the authorization needed for later uploads, and diagnose or secure the workflow. The integration does not publish videos automatically.

Storage and service providers

The integration runs through GitHub Actions. TikTok credentials and refresh-token state are intended to be stored as GitHub Actions secrets and encrypted state, respectively. Video artifacts and workflow logs may be retained by GitHub according to the repository and GitHub Actions retention settings. TikTok receives the video and related upload data as part of the upload process and handles them under TikTok's own policies.

Sharing

We do not sell personal information. Information is shared with TikTok only as needed to perform the upload you request, and with GitHub as needed to run and store workflow data. We do not intentionally collect information for advertising.

Retention and control

Workflow artifacts and logs are retained according to the configured GitHub settings. You can stop using the integration and revoke its authorization through your TikTok account's connected-app settings. You can also remove the related GitHub Actions secrets to prevent further uploads.

Security

Reasonable safeguards are used, including encrypted storage for refresh-token state and GitHub's encrypted secrets. No internet service can guarantee absolute security.

Children

The Service is not designed to collect personal information from children.

Changes and contact

This policy may be updated as the Service changes. For privacy questions, contact the project maintainer through the Ringshift GitHub repository.
